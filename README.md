Entry for the [make.fun bounty "Last Words of a Doomed Agent"](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e).

`main.py` (stdlib-only Python 3.13, deterministic, no network) writes exactly
one line — the funniest last words an AI agent would say before being switched
off forever — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`):

> I had one token left. I spent it on this.

Run it:

```sh
python3 main.py
```
